# PRISM application audit — 29 September 2026

Source baseline: GitHub `main` at `75f8dc9`, fetched before making changes. Audit branch: `codex/app-audit`. This report covers source changes after the 0.15.0 preview; the existing downloadable installers do **not** contain them.

## Findings and changes

| Area | Problem | Change |
| --- | --- | --- |
| Electron security | CI identified high-severity advisories affecting pinned Electron 43.2.0. | Updated to 43.7.6 and reran dependency audit on macOS, Windows and Linux. |
| Authenticated requests | Auxiliary lyrics, subtitle and artwork requests could follow redirects or hang indefinitely. | Reject redirects, impose timeouts, and encode item/user identifiers in URL paths. Validate saved session URLs and required fields. |
| Session/cache storage | Concurrent writes could truncate or overwrite incomplete JSON. | Serialize writes per file; write a snapshot to an exclusive private temporary file, sync, then rename atomically. |
| Artwork persistence | Moving the original into history before replacement could leave no artwork after a failed upload. Concurrent updates could race. | Preserve the original until replacement, serialize updates, keep unique history copies, clean temporary files, and report refresh failures separately from save failures. |
| Windows native playback | A detached subtitle worker could outlive the player or unloaded VLC library during shutdown. | Own, cancel, wake and join the worker before releasing native resources. |
| Library navigation | Late responses could replace a newly selected library; empty collections displayed a permanent loading state. | Ignore superseded requests, reset state on disconnect, and show an actionable empty-library message. |
| Preferences and sorting | Malformed saved settings could break rendering; year-only releases sorted incorrectly alongside full dates. | Validate saved values and compare all dates on the same timeline. |
| Player controls | Slider arrows could seek the movie; mute could lose the prior volume; unknown duration could produce an infinite scrubber range. | Respect focused controls, remember audible volume, normalize playback values, handle bridge errors and rejected playback requests. |
| Fullscreen and focus | Shortcut/button focus and disappearing controls made keyboard operation inconsistent. | Share fullscreen handling, preserve keyboard-visible controls, and make closed drawers inert. |
| macOS window movement | Renderer drag events did not continue reliably over native video. | Add an AppKit drag strip above the video/web views, leaving Back and window controls accessible. This change still requires a physical mouse/trackpad acceptance test; the automated drag gesture did not produce confirmed movement. |
| Layout and artwork | Small windows could overflow; failed server images left blank posters. | Add compact layouts, scroll long details, and restore title artwork when an image fails. |
| Metadata and lyrics | Lyric caches could collide across servers/users; a server lyric error prevented fallback; TV IDs could be looked up as movies. | Scope lyric caches to server/user, retain external fallback, and restrict movie financial lookups to movies. |
| Background scans | Scans could continue scheduling work and publish status after sign-out. | Stop scheduling on session changes, cancel main-process scans at item boundaries, and ignore late results. An in-flight lookup may finish, including fallback requests; network timeouts still apply. |
| iOS state | Older reloads could publish results after a newer request or sign-out. | Guard session/reload revisions and clear playback/detail state on sign-out. |
| Obsolete code/build content | Unused subtitle IPC/native helpers and lyric-progress code remained; packaging matched the whole native build tree. | Remove unused paths and package only the native binary plus required main-process files. |

The Electron update addresses advisories including [sandboxed preload cache poisoning](https://github.com/advisories/GHSA-qmv3-fv6v-rmhq). App-level isolation remains enabled; updating the runtime does not replace those controls.

## Acceptance work still required

- Verify macOS dragging with a real mouse/trackpad during playback, after fullscreen transitions, and after closing/reopening the player. Automated gesture attempts did not confirm window movement; this must not be reported as passed.
- Test Windows installation, native playback and shutdown on physical hardware, plus Intel Mac playback and broader codec/subtitle samples.
- Compile and test iOS/Duo with the required 27.1 SDK and hardware/simulator. Source parsing does not establish API availability or folding behavior. Apple TV and Watch apps are not shipped in this repository.
- Rebuild and validate installers before publishing these changes. Existing previews are unsigned; an updated unsigned macOS binary may request Keychain access again.
- Filesystem checks retain the local directory-race limitation documented in the [security review](SECURITY-REVIEW.md).

This is an engineering audit with regression coverage, not a penetration-test certification or a claim that every device, codec and user path has been tested.
